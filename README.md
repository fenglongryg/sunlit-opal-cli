# sunlit-opal-cli

Mobile developer · Flutter and Dart · archiving old docs

学习用的示例项目

## 用法

```bash
cat data.txt | node index.js
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/sunlit-opal-cli.git
cd sunlit-opal-cli
npm install
```
